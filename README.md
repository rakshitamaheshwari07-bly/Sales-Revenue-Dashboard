# Sales & Revenue Analysis Dashboard 📊

## Overview
An interactive Sales & Revenue Analysis Dashboard built using Microsoft Excel.

## Features
- 70+ sales transactions analyzed
- 4 Interactive PivotCharts
- Monthly Revenue Trend
- Product-wise Sales Analysis
- Category-wise Revenue Split
- Region-wise Sales Comparison

## KPIs Tracked
- Total Revenue
- Total Units Sold
- Average Order Value
- Max & Min Sale Value

## Tools Used
- Microsoft Excel
- PivotTables & PivotCharts

## Outcome
Learned data visualization, KPI tracking and business insight generation.
